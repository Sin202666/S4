# 3C 下落粒子表现 V3（动态验收待续）

按参考视频逆向拟合黑白尖梭速度线。当前未达到可证明的逐帧 1:1：原工程参数、镜头和随机种子未知。起跳风圈不属于本次范围。

## 参考与评价

参考为 30 FPS：约 1.43s 出现首批线条，1.50s 展开，1.70s 着地，1.90s 余线消失。时间是画面观察值，误差至少一帧。旧线向上离开，不同位置有新线补入，故采用持续补线。

用户评价 V2 没有抓住参考的手感和质感。撤回此前 8/10 的主观评分，不以参数变化或单张截图代表还原成功。复查确认两个问题：Size 同时缩短、变细，短划失去实度；手动按 Heartbeat 补发，在约 10 FPS 的录制中呈现同龄粒子成簇的空隙。

V3 用 16 帧序列改变线长，保留线宽至末段；改用原生 Rate 连续发射，目标是修复成簇补线。序列贴图已加载、单粒播放已检查，最终 Rate 版仍需连续实机复验。不能把此状态标记为 1:1 验收通过。

## 逻辑

| 模块 | 职责 |
|---|---|
| FallVfxState | 纯状态机、触发门槛、累计发射数、落地重置、中断清理 |
| FallVfxVisual | 序列贴图粒子、原生 Rate 开关、发射源跟随和销毁 |
| FallVfx | 读取 Humanoid、速度和接管条件，驱动状态与视觉 |
| Animate / AnimateFov | 生命周期；沿用 FOV 合成入口，默认增量为零 |

`Idle → Armed → Burst → Falling → Release → Idle`

1. Freefall 且 FloorMaterial=Air，实际下降至少 0.50s、累计下降至少 16 studs、向下速度至少 80 studs/s 才开始；普通短跳不触发。
2. 每色原生 Rate=90，起效只额外 Emit(1)，不再把累计预算按帧成簇发射。状态机的 emitCount 保留为理论预算诊断值，不是实际 GPU 粒子数。
3. FacingCamera、固定竖向、LockedToPart=false。仅发射源跟随，粒子以 29.4–42 studs/s 向上移动。Grid4x4 / OneShot 随单粒寿命播放，首段拉长，中后段缩成保持线宽的短划。
4. 着地当帧禁用发射器，余粒按序列播放收尾，最长约 0.24s；不会 Clear 普通落地的尾迹。既有落地反馈独立处理。
5. 空中停止下降、低于退出速度 26、或接管中断后，同次空中阶段不重播；真实落地重新武装。死亡、异常帧、明显传送等立即 Clear。
6. 销毁角色时释放自有实例；不修改角色速度、姿态、重力或相机，无新 Remote，仅本地玩家表现。

业务可设置角色属性 `FallVfxDisabled=true` 禁止表现，接管条件沿用 Animate 原有 suppression 判定。

## 参数与开销

| 参数 | 值 | 用途 |
|---|---|---|
| particleSize / particleSizeVariance | 1.9 / 0.20 | 线长与随机尺寸比例，配合 Squash=0.6 保持细长轮廓 |
| emitterHeight | 1 | 发射体中心相对根节点高度 |
| emitterExtent / emitterVerticalExtent | 3.6 / 8 | 水平宽度与竖直分布 |
| lifetimeMin / lifetimeMax | 0.17 / 0.24 | 单粒序列播放时长 |
| particlesPerSecond | 90 | 每色原生 Rate |
| maxFov | 0 | 不增加参考中未确认的镜头效果 |

稳态理论平均约 37 个存活粒子；帧循环不创建实例或 NumberSequence。实际可见数量受尺寸、透明度、镜头和遮挡影响。移动端尚未实机测量，可降低 particlesPerSecond。
