# 扳手腕数值设计说明

> 对应导表：`config/AWConst.xlsx`、`AWMaterial.xlsx`、`AWArm.xlsx`、`AWDumbbell.xlsx`、`AWUpgrade.xlsx`、`AWLevel.xlsx`、`AWEnemy.xlsx`  
> 运行时入口：`ArmWrestleConfig`（组装表数据 + 稀有度/IAP/药水仍在代码）  
> 本文说明**为什么这样定**，不是字段字典。

---

## 1. 设计目标

1. **前 5 分钟能赢**：新手空手打过第一关弱怪，立刻拿到现金与第一档成长感。
2. **纵向膨胀可读**：力量/现金用 K/M/B/T 展示；每关约一个数量级台阶，玩家能感到「进新区了」。
3. **多通道叠乘**：力量 = 训练基础 × 手臂 × 材质 × 哑铃 ×（通行证/档位/药水）；现金另乘好友/会员/双倍金。任一通道都不唯一通关条件，避免单点付费墙。
4. **对局是节奏游戏不是数值碾压**：`TapPower` / `OpponentDrift` / `BattleTime` 保证「略强可稳赢、略弱可靠手速翻盘、差太多也不至于秒杀」。

---

## 2. 对局手感（AWConst）

| 键 | 值 | 思路 |
|---|---|---|
| `BattleTime` | 15s | 短局，适合挂机训练循环里穿插挑战；过长易疲劳，过短手速差异被噪声淹没。 |
| `TapPower` | 0.035 | 单次点击对进度条贡献；配合每秒上限，满速连点约数秒可推满一格优势。 |
| `OpponentDrift` | 0.13 | AI 持续回推；略大于「平均点击吞吐」，所以要持续点才能压住，不能点一下挂机。 |
| `MaxTapsPerSecond` | 14 | 防脚本与不切实际的连点；真人极限附近封顶。 |
| `AutoTapsPerSecond` | 8 | AutoClicker 通行证速度：明显省力，但仍低于手速上限，保留付费与手速的差异。 |

**判胜逻辑依赖相对力量差 + 点击**，配置里没有「一击必杀倍率」。力量主要用于：① 决定你相对对手的起始/漂移优势；② 关卡 Gate 门槛。这样数值膨胀不会直接毁掉点击玩法。

其它常量：

- **离线**：`OFFLINE_RATE=0.1`（在线挂机效率的 10%），最短 5 分钟（Studio 10 秒）、封顶 8 小时——鼓励回访，不鼓励「挂一夜清进度」。
- **好友/会员现金加成**：每好友 +10% 封顶 +50%，Premium +25%，与其它现金倍率**独立相乘**——社交与会员是乘区，不改力量曲线。
- **菜单礼物**：`MENU_GIFT_CASH_MULT=10` × 已解锁关最强对手奖励，每账号一次——挽留用大额现金，不给永久倍率。
- **抽箱冷却 = 演出时长 3.2s**：表演期间不能连扣钱。

## 3. 关卡与对手（AWLevel + AWEnemy）

五关主题递进：公园 → 峡谷 → 沙漠 → 雪山 → 火山。每关 **3 个对手**，Power / Reward 约呈 **2.5～3×** 链，关与关之间约 **一个数量级**：

| 关 | Gate（入场力量） | Boss Power | Boss Reward | 角色 |
|---|---|---|---|---|
| 1 青草 | 0 | 40 | 150 | 教程；木箱免费抽、按材质价购买 |
| 2 岩石 | 60 | 700 | 2K | Offer 免费抽；购买价在材质表，池偏前期材质 |
| 3 沙漠 | 800 | 12K | 28K | 中期；材质购买价随 Mult 抬档 |
| 4 冰雪 | 15K | 220K | 320K | 后期；奖励略高于 Power，补偿难度 |
| 5 熔岩 | 250K | 4M | 4M | 终局；Reward≈Power，现金与力量叙事对齐 |

**Gate 定法**：略低于本关最弱怪 Power，让「刚够进区」的人仍要成长才能稳通三号位；避免 Gate 高于 Boss 导致进门即卡死。

**Scale**：设计意图是对手模型缩放（弱怪略缩小、Boss 放大），纯表现、不参与结算。**当前业务代码尚未读取该字段**（场景对手多为预摆模型），改数暂不影响玩法。

**抽箱池**：每关 4 档材质（第 1 关 3 档 Offer），池整体随关卡上移；权重在 **AWLevel.PoolWeights**（与 `Pool` 按位对齐），**按箱子独立**——同材质可在不同箱有不同掉率；同池内通常仍随 Mult 递减，高倍难抽、低倍托底。

## 4. 成长三件套：手臂 / 材质 / 哑铃

三者都是 **力量乘区**，曲线形状故意不同，避免三张表同构导致「只升一件就够」：

### 4.1 手臂（AWArm）— 主现金成长线

- Mult：1 → 60（12 档），前段密、后段疏（1 / 1.5 / 2 / 3 / 4.5 …）。
- 现金价：约 **3～4×** 上一档（75 → 250 → 600 → … → 600K），与对局 Reward 曲线咬合：打本关 Boss 若干次可够下一臂。
- 末两档改 **Robux**（40× / 60×），审判臂与神圣臂同为付费档、不限量——付费炫耀位，不挡通关（现金臂到 25× 已可覆盖终局节奏）。

### 4.2 材质（AWMaterial）— 抽卡 / Offer 乘区

- Mult：1.2 → 100；掉率不挂材质行，改 UI 稀有度档（Xyd）不影响数学期望。
- 稀有度字段统一为 **Xyd**（number，1 普通 … 7 专属），与物品表 `xyd` / `GetRarity(xyd)` 同语义。
- 可购材质均带 `Price`（购买现金价）；关卡表 **不配价**；奥术 `Price=0` + ProductKey，只走商城。
- 材质机：**抽取免费**，确认购买才扣该材质 `Price`；设计意图是抽给「惊喜尖刺」，买给「材质=倍率」理解。

### 4.3 哑铃（AWDumbbell）— 平稳现金线

- Mult：1 → 14，比手臂更「钝」，价同样指数涨。
- 作用：中等付现投入；外观档位（片色/缩放）随 Mult 变重，强化「装备变强」反馈。

**叠乘直觉**：新手三件套约 1×1.2×1；中期认真养成可到数十倍；末期全满 + 奥术可达数千倍量级，与终局 4M Power 对手同一叙事尺，而不是无限开方。

## 5. 训练与移速阶（AWUpgrade）

| Kind | 含义 | 曲线 |
|---|---|---|
| `TrainSpeed` | 每次训练间隔（越小越快） | 1 → 0.25，五档付费；价 50 → 900K |
| `WalkSpeed` | 世界行走速度 | 16 → 36，对齐 GameConfig 默认走速起点 |

训练阶是 **挂机效率** 主开关：间隔缩短近似线性提升单位时间力量，故价格比手臂更陡，防止「只升训练、不挑战」碾压关卡。移速是 **舒适度付费**，不影响对局结算。

## 6. 未进表、仍在代码的部分

- **稀有度 `_RARITIES`**：键为 Xyd（1..7，普通..专属），与物品表 xyd 同语义；条目字段 `Xyd`；结算不读 Rank。
- **药水效果 `_POTIONS`**：Duration / Mult / Effect / ItemId 仍在 `ArmWrestleConfig`（购买 Robux Id 与价在 ItemShopData；背包物在 ItemData）。
- **商城分区顺序**：`ShopPassOrder` / `ShopPackOrder` / `PotionOrder` / `GamePassOrder` 常量表。
- **路径与动画名**：资产契约，不是平衡数值。

Robux 付费：`ItemShopData`（含 Kind / Tier / Mult / Amount / ArmId / MatId）+ `GamePassItem`；收据与通行证走 `SystemBuyRoblox` / `SystemShop` 表逻辑；通行证落档 `data.GamePass[OnlyTag]`。

---

## 7. 改数时建议检查清单

1. 改对手 Power 时同步看 **Gate** 与 **上一关 Boss**，保持「进区可打、通关要养成」。
2. 改 Mult 时同步看 **该箱 PoolWeights**（AWLevel，与 Pool 对齐）与 **价**（手臂/哑铃），避免高倍又便宜又好抽。
3. 改 `TapPower` / `OpponentDrift` 必须实机连点与 AutoClicker 各测一局。
4. 改表后执行 `scripts/ugit/BuildConfig.ps1`，勿手改 `ConfigInstance.luau`。
5. 可选字段（Robux / Limited / Price）在表里用 **0 表示无**；`ArmWrestleConfig` 组装时会省略，以兼容 `if arm.Robux` 等判断。现金价字段名统一为 `Price`（手臂/哑铃/升级/材质购买）；关卡表不配价。
